## Setup

- **Practice on LeetCode** (better UI than GFG). Striver maps every problem to a LeetCode link.
- **One language only.** Use Python (already comfortable from fastai). Don't switch mid-sheet.
- **Bookmark the sheet** and keep a progress tracker (spreadsheet or Notion).

---

## The Right Solving Loop

The trap: Watch video → code along → mark done → forget in 2 weeks.

Use this instead:

1. Read the problem. **Think for 15-20 minutes** before any hint.
2. If stuck, watch only the *intuition* part of Striver's video. Pause. Code yourself.
3. Watch the full solution only after submitting (right or wrong).
4. **Re-solve the problem 3 days later from scratch.** Non-negotiable. This is how patterns stick.

## When You Hit DP, Slow Down

- Budget **3 full weeks** for DP alone.
- It's pattern recognition, not raw coding.
- Watch Striver's DP playlist in order (1D → 2D → on subsequences → on strings → on stocks → on LIS → partition DP → DP on trees).
- Re-solve every DP problem at least twice.

---

## Don't Do This

- Don't solve in multiple languages "for practice."
- Don't read the solution before trying for 15+ min.
- Don't skip easy problems thinking you "know" them — speed on easies matters in interviews.
- Don't do DSA *and* AI heavy on the same day. Alternate.
- Don't switch sheets mid-way. Finish Striver, then optionally do NeetCode 150 for variety.

---

## After Finishing (Week 12+)

- **LeetCode weekly contests** (Sunday 8 AM IST). Do 1-2 per month minimum.
- **Company-specific tagged questions** on LeetCode for target companies.
- **Mock interviews** on Pramp or with peers. Aim for 5+ before real interviews.
- **Revise the sheet** — re-solve 1-2 old problems daily to keep patterns warm.
